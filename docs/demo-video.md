# Démonstration MedDiag

Interface réelle sur un cas fictif de pneumonie. Caneval Gabrielle est le nom de démonstration de l’utilisatrice ; le patient est fictif et sans lien avec sa santé. Les réponses sont réellement obtenues via Groq, enregistrées puis rejouées sans modification pendant la capture. Aucun résultat de benchmark ni taux de réussite n’est présenté. La relecture finale est explicitement simulée. Aucun score ni prescription n’est affiché dans ce parcours. Les citations sont vérifiées dans la source, sans que cela valide le diagnostic. Voir [la revue détaillée et ses limites](demo-review.md).

Les scripts de préparation et d’enregistrement sont dans `evaluation/`. Les résultats de travail restent locaux.
